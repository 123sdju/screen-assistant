# v1.2.2 手动测试清单

使用同一版本的本地构建或 GitHub Release 产物：

- `release/v1.2.2/ScreenAssistant-Windows-x64.exe`
- `release/v1.2.2/ScreenAssistant-Android.apk`

## Windows 网络申请

- 首次启动 Windows 桌面端，确认主窗口先显示，然后 Windows 才可能显示原生网络访问申请。
- 在原生弹窗中只勾选“专用网络”，不要勾选“公用网络”，完成后 Web 和 Android 均可通过同一局域网网关连接。
- 确认软件没有弹出自定义权限对话框，也没有执行 `netsh`、PowerShell 防火墙规则写入或要求管理员权限。
- 如果电脑已有允许/阻止规则，确认没有弹窗时不把它误判为程序故障；使用 Windows 防火墙设置按需清理旧规则后再做首次申请测试。

## Web 页面布局

- “当前结果”页只显示任务状态、截图缓冲数、配置组、思考流、结果流和错误信息，不显示截图、提交、清空等桌面控制按钮。
- “遥控”页显示整屏截图、多图截图、提交当前缓冲、截图并立即提交、清空截图缓冲、所有 Web/App 上下翻页和配置组切换。
- 遥控页的命令按钮保持统一的普通样式，不突出“截图并立即提交”或其他单一主按钮。
- 验证当前结果、遥控、历史和配置页面之间切换正常，结果字体、专注、刷新和移除连接仍可使用。

## 默认设置和回归

- 新建配置或删除模型的 `max_tokens` 后重新读取，确认默认值为 `8192`。
- 点击桌面端“恢复默认快捷键”，确认按功能顺序显示 `F1`–`F12`，并验证冲突提示和 Esc 取消行为。
- 在桌面、Android App 和 Web 端执行整屏截图、多图截图、提交、清空和配置组切换。
- 验证思考流、结果流、历史、代码回放、托盘、完全退出和 Web/Android 重新配对。

本清单用于 GitHub `v1.2.2` 发布验收。
