# Web 端说明

Screen Assistant Web 是随桌面程序一起提供的浏览器客户端。它不需要单独部署 Node.js、Web 服务器或账号服务；桌面程序启动局域网网关后，浏览器直接访问桌面程序提供的页面。

## 适用场景

- 不安装 Android App，直接在手机、平板或另一台电脑的浏览器中查看结果。
- 在浏览器中发起整屏截图、多图截图、提交缓冲、切换配置组和清空缓冲等桌面操作。
- 查看当前任务的思考流、结果流和文本历史。
- 在浏览器中编辑模型连接、配置组、提示词和 `extra_body`。
- 使用专注模式和结果字体缩放，或与其他已连接 App 同步翻页和字体调整。

截图和模型请求仍由桌面程序执行，Web 端只接收脱敏状态、文本结果和事件通知。

## 前置条件

1. 在 Windows/Linux 桌面端启动 Screen Assistant，并在“局域网与配对”中生成六位配对码。
2. 将浏览器设备和桌面电脑连接到同一个可信局域网。
3. 如果 Windows 防火墙弹窗出现，只允许专用网络访问。
4. 不要把桌面端的 `18765` 端口转发到公网。当前网关使用 HTTP，适合可信内网，不适合不受信任的网络。

桌面网关默认监听 `0.0.0.0:18765`。电脑的局域网地址可以在桌面端“局域网与配对”页面确认；手机上的 `127.0.0.1` 和 `localhost` 指向手机自身，不能替代电脑地址。

## 打开 Web 端

根路径和 `/web` 都返回同一个 Web 页面：

```text
http://<电脑局域网IP>:18765/
http://<电脑局域网IP>:18765/web
```

### 二维码连接

桌面端生成的二维码是直接打开 Web 端的链接，形式如下：

```text
http://<电脑局域网IP>:18765/web?code=<六位配对码>&desktop_id=<电脑ID>
```

用手机相机或浏览器扫码后，Web 页面会从当前地址读取配对码，自动填入电脑地址并发起配对。二维码连接对当前地址具有优先权，不会继续使用浏览器中另一台电脑留下的旧地址或 Token。

### 手动连接

1. 打开上面的 `/` 或 `/web` 地址。
2. 在“电脑地址”中填写 `http://<电脑局域网IP>:18765`，不要填写手机的 `localhost`。
3. 输入桌面端当前显示的六位配对码。
4. 设置一个便于识别的“本机名称”，然后点击“配对并连接”。

配对码有效期为两分钟且只能使用一次。配对成功后，Web 客户端会获得当前浏览器设备独立的 Token，并自动进入主界面。

## 页面功能

| 页面或控件 | 用途 |
| --- | --- |
| 当前结果 | 查看任务状态、截图缓冲数、思考流、结果流和错误；可整屏截图、多图截图、提交缓冲、截图并提交、清空缓冲或切换当前配置组。 |
| 遥控 | 执行桌面命令，并向所有在线 Web/App 广播上翻页、下翻页。 |
| 历史 | 查看桌面保存的文本任务摘要和任务详情；截图路径及截图文件不会通过 Web API 返回。 |
| 配置 | 新增、编辑、删除模型连接和任务配置组，修改提示词、接口格式、URL 模式、思考强度和 `extra_body`，然后保存到电脑。 |
| `A−` / `A＋` | 只调整当前结果正文，范围为 `0.8×–1.8×`，不改变导航和配置界面字体。 |
| 常亮 | 打开 Web 界面后自动申请浏览器 Screen Wake Lock，必要时使用兼容媒体保活；页面回到前台时会自动重新申请，是否可用取决于浏览器能力和当前页面状态。 |
| 专注 | 只保留当前结果和必要状态；退出专注模式后恢复完整页面。 |
| 刷新 | 重新读取桌面快照并重建实时事件连接。 |
| 移除连接 | 停止实时连接，清除本浏览器保存的桌面地址和 Token，回到配对页面。 |

“配置”页面中的 API Key 行为如下：

- 输入框留空且已有 Key 时，保存动作保持电脑上的原值。
- 输入新 Key 时替换电脑上的原值。
- 勾选清除时删除电脑上已保存的 Key。
- Web 页面只显示“已设置/未设置”，不会从桌面端读取已有 Key 内容。

## 实时同步和连接恢复

Web 页面配对后先调用 `/v1/bootstrap` 获取完整快照，再通过带 Bearer Token 的 `/v1/events` SSE 连接接收变化，包括任务状态、思考增量、结果增量、缓冲、配置、翻页和字体事件。

- 短暂的 SSE 断开会保留已配对页面，并自动尝试重新连接。
- 重新连接后，Web 端以新的 bootstrap 快照为准，不补执行断线期间已经过期的遥控事件。
- 旧任务迟到的思考/结果事件会按 `task_id` 丢弃，不覆盖当前任务。
- 如果桌面端撤销了设备，或 Token 失效，页面会清除该 Token 并提示重新配对。
- 切换到另一台电脑时，应使用新的二维码连接；也可以先点“移除连接”再手动输入新地址。

## 浏览器本地保存的数据

浏览器的本地存储只保存连接和显示状态：桌面地址、Web 设备 ID/名称、设备 Token、结果字体比例和专注模式。打开页面后常亮会自动尝试，不需要额外开关。设备 Token 等同于当前 Web 设备的访问凭证，不要复制到聊天、截图或公开 issue 中。

桌面端仍保存真正的运行配置和历史数据：

- API Key 只保存在桌面端配置文件，以及桌面端向模型供应商发出的请求中。
- 截图留在桌面端，不通过 Web API 传输。
- Web 页面可以编辑配置，但不会绕过桌面端的脱敏返回规则。

## 常见问题

### 页面打不开

确认桌面程序正在运行，并在电脑本机先访问 `http://127.0.0.1:18765/health`。如果电脑本机正常、手机打不开，检查手机和电脑是否在同一个 Wi-Fi、Windows 防火墙是否允许专用网络，以及填写的是否是电脑当前局域网 IPv4。

### 配对失败

重新在桌面端生成配对码。配对码两分钟后失效，成功使用一次后也会失效；不要继续使用旧二维码或旧码。若是从另一台电脑切换过来，先移除浏览器中的旧连接。

### 页面已连接但没有实时结果

点击“刷新”重建 bootstrap 和 SSE 连接。若状态提示“连接凭证已失效”，需要重新扫码或重新输入六位配对码；若反复断开，优先检查局域网是否隔离客户端或代理是否缓存 SSE 响应。

### 修改配置后 API Key 看不到

这是预期行为。Web 端只显示 Key 是否已配置；需要更换时输入新 Key，需要删除时明确勾选清除，不会回显原 Key。
