# v1.2.0 手动测试清单

使用同一版本的本地构建或 GitHub Release 产物：

- `release/v1.2.0/ScreenAssistant-Windows-x64.exe`
- `release/v1.2.0/ScreenAssistant-Linux-x86_64.tar.gz`
- `release/v1.2.0/ScreenAssistant-Android.apk`

## 模型与配置

- 新建或编辑模型连接，确认“思考强度”包含自动、none、minimal、low、medium、high、xhigh、max。
- 分别使用 API 根地址、以 `/v1/chat/completions` 或 `/chat/completions` 结尾的完整地址，以及以 `/v1/responses` 结尾的完整地址执行连接测试和截图任务，确认没有重复拼接路径且两类流均正常显示。
- 在“接口格式”中分别验证自动、Chat Completions 和 Responses；自动模式下确认 Chat 端点不存在时可回退到 Responses。
- 选择“完整端点 URL”，填写带自定义路径和查询参数的地址并明确选择响应协议，确认请求严格命中该地址；接口格式保持自动时应阻止调用并提示明确选择。
- 选择“自动”并执行任务，确认兼容服务正常调用；再选择供应商支持的档位并测试连接、执行任务。
- 设置思考强度后，在对应配置组的 `extra_body` 写入 `reasoning_effort`，确认保存被阻止并显示重复字段提示。
- 确认 App 和 Web 可以读取和修改思考强度，但不会显示电脑中已有 API Key。
- 确认超时字段显示为“请求总超时（思考 + 输出）”。
- 在模型仍在思考或输出时重新截图并提交，确认旧内容立即被新任务清空替换，旧任务不再追加内容且不进入历史。

## 局域网发现和配对

- 启动桌面端，确认 mDNS 服务正常发布且没有服务名长度错误。
- 使用 Android App 自动发现 `_screenasst._tcp.local` 并完成配对。
- 分别验证 Android App 的二维码、手动局域网 IP 配对和旧版 JSON 二维码兼容。
- 使用桌面端新二维码在手机浏览器打开，确认自动进入 `/web`、填写地址和配对码并完成配对。
- 手动访问 `http://<电脑局域网IP>:18765` 和 `/web`，确认页面都能加载并可配对。

## Web 客户端

- 确认 Web 端显示当前任务、思考流、结果流、错误状态、历史和配置组。
- 验证 Web 端的整屏截图、提交缓冲、截图并提交、清空缓冲和切换配置组命令。
- 验证 Web 端专注模式只保留当前结果和必要状态；刷新页面后专注模式仍保持。
- 调整 Web 端结果字体到 `0.8–1.8`，确认只影响思考/结果内容，不改变导航和状态栏。
- 使用包含超长单行的 Markdown 代码块，确认 Web 端不出现横向滚动。
- 撤销当前设备 Token，确认客户端停止重试并提示重新配对；旧连接事件不能覆盖新连接。

## 桌面快捷键控制 App/Web

- 在桌面设置中确认四个默认快捷键可见、可重新录制、可清空，并能显示重复冲突。
- 录制过程中按 Esc，确认保留原快捷键。
- Android App 或 Web 停留在“当前结果”页时，验证：
  - `Ctrl+Alt+PageUp` 向上翻页；
  - `Ctrl+Alt+PageDown` 向下翻页；
  - `Ctrl+Alt+Plus` 字体增大 `0.1`；
  - `Ctrl+Alt+Minus` 字体减小 `0.1`。
- 每次触发后确认桌面状态栏显示已发送到的在线客户端数量，客户端顶部状态显示已收到对应控制。
- 客户端切换到遥控、历史或配置页，确认桌面快捷键不会强制切回结果页，也不会延迟补执行。
- 如有两部设备，让 Android/Web 同时停留在结果页，确认两部设备同步响应；将其中一部切到其他页，确认只有结果页设备响应。

## 回归

- 验证整屏、区域、多图截图及桌面预览。
- 验证提交截图、思考流、结果流、历史和代码回放。
- 验证关闭到托盘、隐藏运行、再次启动唤醒和完全退出。

## Linux

- 从 GitHub Release 下载并解压 `ScreenAssistant-Linux-x86_64.tar.gz`，在 Ubuntu 24.04 X11 会话验证整屏截图、拖动区域截图、模型请求、历史、配对、Web 和 App 遥控。
- 验证 X11 全局快捷键；在严格 Wayland 会话若合成器阻止监听，确认按钮、Web 和 App 遥控仍正常且软件不崩溃。
- 确认代码回放控件在 Linux 明确显示不可用，不尝试申请 root 权限。

本清单用于 GitHub `v1.2.0` 发布验收。
